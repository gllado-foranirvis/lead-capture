# The Silent Fleet — design system (còpia local)

- `tokens.css` + `tokens.json`: color (temes `light`/`dark` amb `data-theme`), tipografia, espaiats, radis, layout.
- `components/bundle.js` + `bundle.css`: components React 18 a `window.TSF` (carrega React i ReactDOM abans).
- `components/*/README.md` i `preview.html`: guia i exemple de cada component. Obre un `preview.html` al navegador després d'enllaçar `tokens.css`, `bundle.css`, React, `bundle.js`.
- `README.md` i `mobile-first.md`: brand book i regles mobile first.
- `design-system.json`: índex del sistema (només per a l'artefacte).
